## 2. 技术选型（极简优先）

**自写轻量 i18n，不引第三方库。**

- 理由：需求只有「查表 + 插值 + 即时切换」，无 ICU 复数/日期时区集合需求；仓内已有 Context 模式（toast/tasks/caps）可直接复用；bundle 零新增依赖；避免 i18next 的资源加载器/命名空间/插件体系。
- 实现规模约 120 行：`LocaleProvider` + `useI18n()` + `t(key, params)` + `setLocale`。
- **回锅条件（出现其一再换 i18next）**：需要 ICU 复数/相对时间；词典 > 3000 条需按页面懒加载；要对接翻译平台产出 JSON。

**key 策略：source-text-as-key（gettext 风格）——中文原文即 key。**

- `t('导出')` → zh 直接返回 `'导出'`（**中文侧零翻译工作量**），en 查 `dict.en-US.ts { '导出': 'Export' }`，缺译自动回退中文（永不白屏/不显示 key）。
- 迁移是纯机械动作，可用 codemod 脚本批量做，**零 key 命名错配风险**；英文词典可直接交翻译人员。
- 插值：中文模板串 `导出 ${n} 张` → `t('导出 {n} 张', {n})`；en 值 `Export {n} images`。
- 同中文多义时用可选上下文后缀消歧：`t('打开', { ctx: '按钮' })` → 查 `'打开 [按钮]'`（仅歧义处用，默认不用）。
- 已知代价（写进规范，接受）：中文源文案一改，英文译文失效并回退中文 → 由门禁脚本 `--check-missing` 在每次 web 门禁里报「zh 存在但 en 缺失的 key」清单强制补齐。

**语言偏好持久化：** localStorage `dam.locale`（与密度偏好同机制，不落后端、不做跨机同步——桌面无账号体系）。切换时双写 `document.documentElement.lang` + `dir='ltr'`。首启无偏好时读 `navigator.language`：`zh*` → `zh-Hans`，其余 → `en-US`。

**首版语言清单：`zh-Hans`（默认沿用现状）+ `en-US`。** 语言注册表驱动下拉项，加一门语言 = 新增一个 dict 文件 + 注册一行（§11 开放问题 1 待确认是否首版加 ja/ko/de）。

## 3. 落地形态（UI）

- 落点：**设置页新增「语言 / Language」分区**，位置在「外观」之上（第一屏可见），`data-testid="settings-language"`。
- 控件：原生 `<select>`（语言少、可发现性最好、无键盘/无障碍成本），选项文字用**自称**（`简体中文` / `English`），不随当前语言翻译。旁注一行「切换立即生效，无需重启」。
- 切换即生效：Context state 变 → 全树重渲染（已挂载的浮层/抽屉同样生效）；不需要 reload。
- 顶栏**不加**语言按钮（避免挤占 208px 导航与三栏宽度账）。
- 不新增「语言」页、不占 NAV（低频，一层 Dialog 都不需要，直接设置页分区）。

## 5. 后端文案（Rust）策略 —— 渐进 code 化，不一次性重写

问题：`crates/app-web/src/*` 等处的 `{"error": "中文句子"}`、`hint`、报告文本无法靠前端词表切换。

**E1（盘点，半天）**：脚本扫 `crates/app-web/src`、`crates/svc-*`、`crates/pack-host` 中构造给前端的中文串（`json!({"error"…})`、`ApiError::new`/`bad_*`/`failed(`、`hint:`、`with_hint`），产出 `reports/i18n-backend-strings.md`（文件:行 + 原文 + 是否已有 code）。这一步决定 E2 的真实规模（估计 300–800 条）。

**E2（改造口径）**：每个用户可见错误补 `code`（稳定 snake_case 标识）+ `params`（如 `{"n":3,"path":"…"}`），**中文 `message` 原样保留作 fallback**（零破坏，老前端/未翻译 code 行为不变）。
```json
{ "error": "导入失败：3 张图无法解码", "code": "import_decode_failed", "params": { "n": 3 } }
```
前端 `jfetch` 已解析 `code` → 统一在 `ApiError` 上映射 `errors.<code>` 词条（`t('导入失败：{n} 张图无法解码', params)`，用原文当 key，译文天然对齐），无词条则显示后端中文原文。
**优先级**：先覆盖高频路径（导入/库操作、合规判定与复核、导出、provider 配置与探针、插件装卸），长尾留原文。**不做**：把后端全部改成英文 + 前端只显示翻译（会伤日志可读性与既有测试）。

**不做**：错误消息改成英文后靠前端翻译。后端日志与报告仍需中文可读（用户排障）。

## 6. 行业包文案（插件 manifest / 规则名 / 报告列名）

- 现状：`packs/plugins/{ecommerce,imaging,realestate,segment,upscale}/manifest.json` 的 `name/short_name/summary`、`resources/rules.json` 的 `rules[].name`、`report` 列名全是中文，`PackManager`/合规结果面直接显示。
- 方案（**向后兼容，不升 api_version**）：这些字段同时接受**字符串**（= 全语言通用，现状行为）与**对象**（`{"zh-Hans": "...", "en-US": "..."}`）。
  宿主取值函数 `pick_i18n(value, locale)`：命中当前 locale → 命中 `zh-Hans` → 命中任意 → 原字符串。
  落点：`crates/core-config/src/packs.rs`（manifest 解析）、`crates/pack-host/src/{registry,gateway}.rs`（manifest/规则名下发）、`crates/app-web/src/compliance_api.rs`（判定结果与规则名）。
- 前端按当前 locale 取（API 返回结构里带 `nameI18n?`，前端 `pickI18n()` 选值；无字段时用原 `name`）。
- 官方 5 包补 en（`name/short_name/summary` + 每条 rule `name` + 报告列名）。
- conformance（`tools/pack-conformance/`）加 2 条断言：对象形式可解析、缺当前 locale 正确回退；`docs/industry-pack-protocol.md` 同步说明（可选字段）。
- 第三方/私有包未给 en → 回退中文，**这是可接受边界**（写进 README 的翻译说明）。

## 8. 验收口径（按用户标准：人类便利性 + 真实走查）

1. **切换即时生效**：设置页切 en → 当前页面文字立刻变英文，**无需刷新**；刷新与重启后保持。
2. **无残留中文（硬门禁）**：en 下逐页取渲染后 DOM 文本（CDP：`document.body.innerText`）断言 CJK 计数 == 0，白名单仅限用户数据（文件名/路径/标签值/用户库根名）与未提供 en 的第三方包名。脚本 `scripts/i18n_dom_scan.sh`（复用 `references/e2-ui-cdp-harness.md` 的 e2ui.py）。
3. **布局不破**：en 下在 1024/1280/1440 三档量主区宽度，导航/工具条/表头不折行不竖排（沿用 `ui-landing.md`「三栏宽度账」判据；英文均值比中文长 30–50%，工具条标签 `shrink-0` + `whitespace-nowrap`）。
4. **既有功能不回归**：`pnpm -C web build && pnpm -C web test` 全绿（74 个测试文件）；`cargo test --workspace` 中触及 app-web/pack-host/core-config 的用例全绿；`scripts/test_gate.sh` L0 PASS。
5. **真机走查**：Windows（Lenovo 172.25.45.49）/ macOS 各一次：首启自动英文（系统非中文时）→ 切回中文 → 逐页 F1–F9 主路径走一遍，附证据（截图 + DOM scan 输出），按 `damdesk-testing` 的 L1 流程清单勾。
6. **文案守卫**：`python3 scripts/ui_copy_guard.py` 仍 0 命中（词典值纳入扫描）；`scripts/i18n_extract.py --check-missing` 报 0 缺译（或在卡内明确列出豁免清单）。

## 9. codemod 脚本口径（`scripts/i18n_extract.py`）

- 输入 `web/src/**`。
- 识别并替换：JSX 文本节点、`'…'`/`"…"`/`` `…` `` 里的含 CJK 文案、`placeholder/title/aria-label/label/hint/confirm/toast(...)` 参数。
- 跳过：注释、URL/路由、`data-testid`、CSS 类名、纯标点、含 CJK 的**测试断言**（测试单独一轮改）。
- 输出：替换后的源码 + 追加的 `dict.zh-Hans.ts`（带参条目）+ **待译清单**（key 有序、去重、附出现次数与文件）供 en 翻译。
- `--check-missing`：比对源码里 `t(...)` 的 key 集合与 `dict.en-US.ts`，缺译列出；退出码 1 用于门禁。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| source-text-as-key 改原文导致译文失效 | `--check-missing` 进门禁；改文案的卡必须同 PR 更新 en 值 |
| 英文更长压布局 | 落 §8.3 宽度回归；关键按钮用短英文（Export/Save/Cancel），长句放 `title` |
| 词典与代码双份漂移（词典残留废弃 key） | 脚本加 `--check-unused`（提示但不阻断），每批迁移卡跑一次 |
| 后端长尾错误仍中文 | 明确为可接受边界（§5 优先级），UI 不回退成 key；开放问题 4 |
| 第三方行业包无 en | 回退中文，已文档化为边界 |
| 测试大改被当作「改测试凑绿」 | 测试改造只改**文案取值方式**（断言改用 `dict.en-US` 期望值或 isVisible 结构断言），不改断言语义；卡体写明 |
| 浮层/抽屉内的既有打开实例不刷新语言 | Context 全树重渲染天然覆盖；验收点 1 明确要测一个已打开的 Dialog |

## 11. 开放问题（2026-10-26 用户裁决：全部按建议）

1. **首发语言清单**：`zh-Hans + en-US` 两种（架构支持扩展，加语言 = 加一份 dict）。ja/ko/de/es 不在首批。
2. **默认语言**：首启跟随系统语言（`navigator.language`；zh* → zh-Hans，其余 → en-US），用户可在设置页改并持久化。
3. **交付物语言**：导出报告 / manifest / CSV 列名**跟随界面语言**（生成时语言落盘，历史报告不回溯）。
4. **后端错误 code 化范围**：**高频路径优先**（导入/库操作、合规判定与复核、导出、provider 配置探针、插件装卸），长尾保留中文原文兜底；不做全量重写。
5. **RTL**：不做（`dir` 恒 ltr），需要时另开卡。
